## 简报卡片点击后没有置灰
- 修复原因（第一次）：`_disable_card_button` 用 `im.messages-mget` 取原卡片内容，但飞书返回的是 markdown fallback 文本，不是 JSON，导致 PATCH 失败。
- 修复原因（最终）：即使事件 payload 的 `card_content` 也不是原始 JSON——飞书会回显并把 button 的 `value` 替换为 `custom_action_id` + `behaviors`，用事件里的 JSON 也找不到 `value.key`。必须用 bot 自己发送时的原始 card JSON 做 PATCH。
- 修改文件：
  - `partner/core/events.py`: `CardAction` 新增 `card_content` 字段。
  - `partner/office/messaging.py`: `send_card` 发送成功后把原始 card JSON 缓存到 `~/.feishu-partner/card-cache/{message_id}.json`；提供 `load_card_cache`。
  - `partner/ops/serve.py`: `_disable_card_button` 优先加载本地缓存的原始 card JSON 来查找 `value.key`，找不到才 fallback 到 mget。
  - `~/.feishu-partner/run_serve.sh` + 新增 `serve_daemon.py`: Mac 没有 `setsid`，用 Python 守护进程的方式后台运行 serve，启动前清理旧 `lark-cli event consume` 进程，崩溃后自动重启。
- 验证：飞书真实点击事件已收到，日志稳定输出 `disable-card: patched om_xxx key=om:xxx...`；按钮置灰已生效。
