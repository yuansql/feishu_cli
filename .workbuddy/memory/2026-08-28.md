## 简报卡片点击后没有置灰
- 修复原因：`_disable_card_button` 用 `im.messages-mget` 取原卡片内容，但飞书返回的是 markdown fallback 文本，不是 JSON，导致 PATCH 失败、按钮状态不会更新。
- 修改文件：
  - `partner/core/events.py`: `CardAction` 新增 `card_content` 字段；`extract_card_action` 从事件 payload 的 `card_content` 解析卡片 JSON。
  - `partner/ops/serve.py`: `_disable_card_button` 优先使用事件带来的 `card_content` 进行 PATCH，保留 mget 作为 fallback；对 `act=done/fu_done` 都传入 `card=act.card_content`。
- 验证：34 相关 tests 通过；smoke 16/16 通过；本地模拟 disable 成功把按钮 text 改成「已处理」并设置 disabled=True；serve 已重启。
